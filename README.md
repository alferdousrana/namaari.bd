# Namaari ERP

Namaari ক্লোদিং ব্যবসার অর্ডার, স্টক, হিসাব, সোশ্যাল মিডিয়া ও দৈনিক কাজের অ্যাপ।
HTML + CSS + JavaScript দিয়ে বানানো, GitHub Pages এ চলে, ডেটা থাকে Firebase এ।
ফোনে অ্যাপের মতো ইনস্টল করা যায় এবং ইন্টারনেট ছাড়াও কাজ করে।

---

## ধাপ ১ — Firebase প্রজেক্ট তৈরি (১০ মিনিট)

1. https://console.firebase.google.com এ গিয়ে **Add project** চাপুন। নাম দিন যেমন `namaari-erp`। Google Analytics বন্ধ রাখলেও চলবে।
2. **লগইন চালু করুন:** বাম মেনু → **Build → Authentication → Get started** → **Sign-in method** ট্যাব → **Email/Password** → Enable → Save।
3. **নিজের অ্যাকাউন্ট বানান:** Authentication → **Users** ট্যাব → **Add user** → আপনার ইমেইল ও একটি শক্ত পাসওয়ার্ড দিন।
   (অ্যাপে কোনো "সাইন আপ" বাটন নেই — নিরাপত্তার জন্য ইউজার শুধু এখান থেকেই বানানো যায়।)
4. **ডাটাবেস তৈরি:** **Build → Firestore Database → Create database** → লোকেশন `asia-south1 (Mumbai)` বা কাছের যেকোনো একটি → **Production mode** → Create।
5. **নিরাপত্তা নিয়ম বসান:** Firestore → **Rules** ট্যাবে এই প্রজেক্টের `firestore.rules` ফাইলের পুরোটা কপি করে পেস্ট করুন।
   `your-email@gmail.com` এর জায়গায় ধাপ ৩ এর ইমেইল লিখুন (ছোট হাতের অক্ষরে) → **Publish**।
   স্টাফকে অ্যাক্সেস দিতে চাইলে: `['apnar@gmail.com', 'staff@gmail.com']` — আর ধাপ ৩ এর মতো তার ইউজারও বানান।
6. **ওয়েব অ্যাপ কনফিগ নিন:** ⚙️ **Project settings → General** → নিচে **Your apps → `</>` (Web)** → নাম দিন → Register।
   যে `firebaseConfig = { ... }` দেখাবে সেটার মানগুলো `assets/js/firebase-config.js` ফাইলে বসান।

> `apiKey` গোপন কিছু নয় — এটা পাবলিক থাকাই স্বাভাবিক। আসল সুরক্ষা হলো ধাপ ৫ এর Rules।

## ধাপ ২ — GitHub Pages এ চালু করা

1. https://github.com এ নতুন রিপোজিটরি বানান, যেমন `namaari-erp` (Public রাখুন — ফ্রি Pages এর জন্য দরকার; ডেটা Firebase এ থাকে, তাই কোড পাবলিক হলেও ডেটা নিরাপদ)।
2. এই ফোল্ডারের **সব ফাইল** পুশ করুন (`.nojekyll` ফাইলটিও):
   ```bash
   cd namaari-erp
   git init
   git add .
   git commit -m "Namaari ERP"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/namaari-erp.git
   git push -u origin main
   ```
3. রিপোজিটরি → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, ফোল্ডার `/ (root)` → Save।
   ১-২ মিনিট পর লিংক পাবেন: `https://<ইউজারনেম>.github.io/namaari-erp/`
4. **Firebase এ ডোমেইন অনুমতি দিন:** Firebase → Authentication → **Settings → Authorized domains → Add domain** → `<ইউজারনেম>.github.io`

এখন লিংকটি খুলে ধাপ ১.৩ এর ইমেইল/পাসওয়ার্ড দিয়ে লগইন করুন।

## ধাপ ৩ — পুরোনো এক্সেলের ডেটা আনা

অ্যাপে **সেটিংস → এক্সেল থেকে ইমপোর্ট** → `Namaari_Business_ERP.xlsx` বাছাই করুন → **যোগ করুন**।
পণ্য, সাইজ/রং, কাস্টমার, সাপ্লায়ার, অর্ডার, ক্রয়, খরচ ও ক্যাশবুকের মূলধন এন্ট্রি চলে আসবে।
একই কোডের (PRD-001, SOL-001…) ডেটা আবার ইমপোর্ট করলে ডুপ্লিকেট হয় না, আপডেট হয়।

## ধাপ ৪ — ফোনে অ্যাপ হিসেবে ইনস্টল

- **Android (Chrome):** লিংক খুলুন → মেনু ⋮ → **Install app** / **Add to Home screen**। অথবা অ্যাপের সেটিংস পাতায় "ইনস্টল করুন" বাটন।
- **iPhone (Safari):** লিংক খুলুন → Share বাটন → **Add to Home Screen**। (iPhone এ নোটিফিকেশন শুধু হোম স্ক্রিন থেকে খুললে কাজ করে।)

## রিমাইন্ডার কীভাবে কাজ করে

- **আজকের কাজ** পাতায় রিমাইন্ডার যোগ/বন্ধ করা যায় এবং **নোটিফিকেশন চালু করুন** চাপতে হয়।
- অ্যাপ খোলা থাকলে (বা ব্যাকগ্রাউন্ডে থাকলে) সময়মতো নোটিফিকেশন আসে। দিনের পোস্টের টার্গেট পূরণ হয়ে গেলে পোস্ট-রিমাইন্ডার আর আসে না।
- **অ্যাপ পুরো বন্ধ থাকলে** কোনো ওয়েব অ্যাপ নিজে থেকে নোটিফিকেশন দিতে পারে না (তার জন্য সার্ভার লাগে)।
  তাই **"ফোনের ক্যালেন্ডারে যোগ করুন"** বাটন একটি `.ics` ফাইল দেয় — খুললে Google Calendar / iPhone Calendar এ রিমাইন্ডারগুলো প্রতিদিনের অ্যালার্ম হিসেবে বসে যায়।
  রিমাইন্ডারের সময় বদলালে ফাইলটি আবার ইমপোর্ট করুন (আগেরগুলো ক্যালেন্ডার থেকে মুছে দিন)।

| গ্রস লাভ | বিক্রি − বিক্রিত পণ্যের কেনা দাম |
| নিট লাভ | গ্রস লাভ − ব্যবসার খরচ |
| মালিকের উত্তোলন | সেটিংসে "ব্যক্তিগত" বাছাই করা খরচের ক্যাটাগরি (ডিফল্ট: Personal Cost) লাভ কমায় না, আলাদা দেখায় |
| অ্যাকাউন্ট | প্রতিটি পেমেন্ট মাধ্যম (Cash, bKash, Bank…) আলাদা ব্যালেন্স। বিকাশ থেকে ক্যাশ তুললে ক্যাশবুকে "ট্রান্সফার" দিন |
| ব্যালেন্স শিট | সম্পদ = দায় + মালিকানা — রিপোর্ট → ব্যালেন্স শিটে মিলছে কিনা দেখায় |

## নিয়মিত কাজ

- **ব্যাকআপ:** মাসে একবার সেটিংস → **ব্যাকআপ ডাউনলোড (JSON)**। দরকারে "ব্যাকআপ রিস্টোর" দিয়ে ফেরত আনা যায়।
- **কোড আপডেট করলে:** `sw.js` এর ভেতরে `VERSION = 'namaari-v1'` বাড়িয়ে `v2`, `v3` করুন, নইলে ফোনে পুরোনো ভার্সন থেকে যেতে পারে।
- **Firebase খরচ:** ফ্রি (Spark) প্ল্যানে দিনে ৫০,০০০ রিড / ২০,০০০ রাইট — এই ব্যবসার জন্য যথেষ্ট।

## Firebase ছাড়া চালানো (লোকাল মোড)

`firebase-config.js` এ কনফিগ না বসালে অ্যাপ "লোকাল মোডে" চলে — লগইন লাগে না, ডেটা শুধু ওই ব্রাউজারে থাকে।
চেষ্টা করে দেখার জন্য ভালো, কিন্তু আসল ব্যবহারের আগে Firebase সেটআপ করুন।
লোকাল মোডের ডেটা ক্লাউডে নিতে: ব্যাকআপ ডাউনলোড → Firebase সেটআপ → লগইন → ব্যাকআপ রিস্টোর।

কম্পিউটারে চালিয়ে দেখতে (ফাইল সরাসরি ডাবল-ক্লিক করলে কাজ করবে না):
```bash
cd namaari-erp
python -m http.server 8000
# ব্রাউজারে http://localhost:8000
```

## ফাইল কাঠামো

```
index.html                 অ্যাপের মূল পাতা
manifest.webmanifest       ইনস্টলযোগ্য অ্যাপের তথ্য
sw.js                      অফলাইন ক্যাশ + নোটিফিকেশন
firestore.rules            Firebase নিরাপত্তা নিয়ম
assets/css/app.css         ডিজাইন (লাইট/ডার্ক থিম)
assets/js/firebase-config.js   ← এখানে Firebase কনফিগ বসাবেন
assets/js/app.js           শেল, রাউটিং, লগইন
assets/js/core/            হিসাব (calc), ডেটা (store), এক্সেল ইমপোর্ট, রিমাইন্ডার
assets/js/views/           প্রতিটি পাতা (অর্ডার, স্টক, রিপোর্ট, সোশ্যাল, আজকের কাজ…)
```
